There may be instances where you will see "value is in [a, b]", this is an "interval notation", for example:

[0, 5] is from 0 to 5, including 0 and 5.

(0, 5] is from 0 to 5, including 5 but not including 0.

[0, 5) is from 0 to 5, including 0 but not including 5.

(0, 5) is from 0 to 5, excluding 0 and 5.
