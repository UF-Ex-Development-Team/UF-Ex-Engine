Welcome

Welcome to the introduction section of the UF-Ex documentation, here you can find tutorials and frequently asked questions on how to use the UF-Ex SDK.

UndyneFight-Ex, or UF-Ex for short, is a .NET SDK used to create Undertale themed rhythm games for desktop PCs using the language C#, with the implementation of MonoGame Framework, MonoGame Extended, NAudio, Newtonsoft, and NVorbis. The SDK was used to create Rhythm Recall, and now Rhythm Recall Rcade.

This SDK is the continuation of the incomplete version of the SDK which was open sourced along with the incomplete Rhythm Recall v0.2.2 in here. This SDK provides additional features such as:

  • Localization
  • Additional utilities for development
  • Audio preview for charts
  • Rebinding keys
  • Multiple BPM in charts
  • User defined easing functions
  • Typo correction in codes
  • Documentation of codes
  • Optimization to codes
  • And more

This documentation aims to help you get started with developing using this SDK with a step by step guide from setting up to publishing your game.

Send help

Code

This open sourced (since 2025) project is maintained by only one person and a few bug testers, it would be great if you can help by reporting bugs, make a feature request, or even create a pull request to help development gain momentum.

Documentation

As mentioned above, this project is maintained by one person only, so the production speed of the documentation would be slow, if you have a good understanding on how UF-Ex works, you can help by creating guides, videos, or improvements to the documentation to further help other people understand how to use this SDK.

Cross platform

UF-Ex is (currently) a Windows only SDK, and that is obviously not very friendly to people who aren't using Windows. If you have a non-Windows machine and knows coding, you can help by testing whether this SDK can run smoothly on different machines.
