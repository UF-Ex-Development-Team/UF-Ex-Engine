Preface

While the official Microsoft and Monogame recommends using .resx files, UF-Ex uses .json files for more flexibility and readability, so people can implement their own translations easily. The .json file generated by the game will be put in Roaming/{GAME_NAME}/Localization, you can create more translations by copying the .json file and renaming it.

Creating a translation

The first set of data should be Fonts, they define what fonts to use for GlobalResources.Font.NormalFont, GlobalResources.Font.FightFont, and GlobalResources.Font.DamageFont and its scale.

"Fonts": {
    "NormalFont": {
        "Path": "NormalFont",
        "Scale": 1
    },
    "FightFont": {
        "Path": "FightFont",
        "Scale": 1
    },
    "DamageFont": {
        "Path": "DamageFont",
        "Scale": 1
    }
}

These are the default values of each font, if you would like to use a custom font for another language, you can type in the path to the font for the game to load, i.e.

"Fonts": {
    "NormalFont": {
        "Path": "Font/NewNormalFont",
        "Scale": 0.8
    }
}

If the font is of a different scale than the original font, you can modify Scale to a different value for the new font to scale for that factor, so in this case the new font will be 0.8x its size when displayed in the game.

In some entries, you would see something like

"AudioPreview": "Loading audio previews: {0}/{1}"

{0}, {1}, ... ,{x} are parameters used in the game, please make sure the amount of parameters remain consistent in the translated text.

Using translations

The most straightforward method on drawing localized text is to use Localization.DrawLocalizedText, for example:

Localization.DrawLocalizedText("Challenge.Result", new Vector2(320, 31), align: Localization.DrawAlign.Middle);

This draws a centered text at (320, 31), where the text is Result that is nested inside Challenge.

For texts that have parameters, you can draw the text like this:

Localization.DrawLocalizedText("SplashScreen.AudioPreview", new Vector2(320, 320), [LoadedPreviewAudioCount, AudioPreviewDatas.Count], color: Color.White * MathF.Abs(Functions.Sin(appearTime)), scale: new Vector2(0.6f), depth: 0.98f, align: Localization.DrawAlign.Middle);

The third argument in the function will substitute LoadedPreviewAudioCount and AudioPreviewDatas.Count into the text's {0} and {1}.

There are some other localization functions you can use:

Name Use
Localization.GetText Gets the text of the specified key in the current language
Localization.GetFont Returns the target font for the current language
Localization.GetFontScale Gets the scale of the localized font
Localization.GetFontData Gets the font data of the localized font
