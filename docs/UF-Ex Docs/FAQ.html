Frequently Asked Questions

Q. The documentation isn't available in my language, can you add it?

A. Since the documentation is currently in its very early stages, I don't plan on making translations, you can use machine translation or make a fork with your own localization, but you should keep in mind that I would update the documentation from time to time and that the English documentation would be the most accurate.

Q. Can UF-Ex SDK be used on Linux/MacOS/Other OS?

A. Technically yes, since there shouldn't be any platform specific codes in here, so you can compile your game to different platforms, but since I don't have other devices, I can't test them; please report any issues should you find any.

Q. There is a bug in the SDK, and it scares/annoys me, should I make workarounds?

A. You can, but it's best to report the bug in Issues or in the Discord server, I check them once every one or two days to make sure nothing goes wrong.

Q. I think there is a feature that you can add to make UF-Ex more useful and I'd like you to implement it!

A. Cool! Please make a feature request in Issues or in the Discord server. I love spending my time to make UF-Ex better.

Q. UF-Ex lags randomly and it annoys me >:(

A. Then perhaps I can optimize UF-Ex even more, please report it as a bug in Issues or in the Discord server.

Q. My chart crashed/acts differently while playing in Rhythm Recall Rcade as a custom chart, why did this happen?

A. It is likely that Rhythm Recall Rcade has a different SDK version than your chart, i.e. your chart is running on 0.3.0 and Rhythm Recall Rcade is running on 0.4.0. It is likely that you will need to re-release the custom chart in the newest SDK version to ensure it can be processed by Rhythm Recall Rcade.

Q. Some functions are marked as "Obsolete", should I use them?

A. No, this is why I marked them as "Obsolete". They are usually legacy functions that are outdated and have better alternatives, they are kept in the SDK because some charts in Rhythm Recall Rcade still require them to function, but they will be phased out as time passes.
