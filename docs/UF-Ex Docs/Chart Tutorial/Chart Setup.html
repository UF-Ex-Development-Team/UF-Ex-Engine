Importing music

By pressing (Ctrl +) F5, the game should run normally.

Tip

Ctrl + F5 will not attach the debugger to the executable, it will run faster but will not show an error log if the game crashes.

If you try to select a song, you should see this.

A bracket indicates that there is no associated music file for the chart, that means you need to import it. To import assets, select “Content.mgcb” in the “Content” folder

You can just double click it or choose “Open With -> MGCB Editor”. If there is no such folder named “Musics”, create one by right clicking “Content”, and select “Add -> New Folder” and name it “Musics”.

After having the “Musics” folder, create a folder that matches the name of the chart, in this case, it would be “My First Chart”. Right click on the newly created folder and select “Add -> Existing Item”, then you can select the music you want to import, make sure it says the imported music is set to a song. After importing the music, rename the music asset into “song.(file type)” (If the music you imported was an .wav file, name it to song.wav, and so on) If you want to add a chart cover, simply import an image file and rename it into “paint.png”.

Important

In this tutorial, go to Tutorials/00. Assets and copy Neo.ogg.

Note

The engine has auto scaling for chart covers, but it is best to set it to a 4:3 ratio to avoid visual bugs.

After importing the chart assets, make sure to “Build” the MGCB by pressing F6.

Tip

It is best to use “Rebuild” if you have removed or renamed assets so the previous file cache will be removed.

Basic template information

Some comments are inside Normal Model and Championship Model to help you understand each aspect. In this tutorial, we will start from Normal Model, Championship Model will be discussed later.

  • IWaveSet (Classic)
  • IWaveSetS (Simplified) 
class MyFirstChart : WaveConstructor, IWaveSet

WaveConstructor contains the basic methods for charting such as beat calculation and the main chart making function. IWaveSet is the interface that stores the basic information of the chart, such as the difficulties and music name.

public MyFirstChart() : base(62.5f / (100 / 60f)) { }

The “100” is the BPM of the chart, if you are unsure of the BPM, you can use an online BPM checker or use Malody (More accurate) to find the BPM of the music. If there are multiple BPM in the chart, simply put them in arrays like this:

public MyFirstChart() : base([10, 300], [10, 50], [999, 230]) { }

This means that the first 10 beats have 300 bpm, the next 10 beats have 50 bpm, and the next 999 beats have 230 bpm.

Most information are already provided in "Normal Model.cs", you may view the basic setup there.

Sometimes, you may find that you need to copy and paste chunks of code from one difficulty to another, and when you need to change certain aspects of the code, you need to manually change them all. Not only is this process boring and tedious, it makes the code unreadable and too large. In short, this is poor coding practice and should be avoided.

To simplify the charting process, IWaveSetS is created, your code can now look as simple as this

public void Chart()
{
    Effect();
    switch (CurrentDifficulty)
    {
        case Difficulty.Noob:
            //Noob mode
            break;
        case Difficulty.Normal:
            //Normal mode
            break;
    }
}

Or even this

public void Chart()
{
    if (InBeat(0))
    {
        int spd = CurrentDifficulty switch
        {
            Difficulty.Noob => 4,
            Difficulty.Easy => 5,
            Difficulty.Normal => 6
        }
        CreateChart(0, BeatTime(1), spd, ["R", "", "", "etc"]);
    }
}

Not only is the code more efficient, it is more readable and easy to keep track of.

Setting up chart information

As mentioned above, you should first input the BPM of the music, in this case, Power of NEO has a BPM of 36.25, so instead of the default

class MyFirstChart() : WaveConstructor([(20, 100), (20, 200)]), IWaveSet

You should modify it to

class MyFirstChart() : WaveConstructor(36.25f), IWaveSet
